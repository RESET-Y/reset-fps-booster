Game Boost Mode

Detects your game. Deprioritizes everything else. Restores it the moment you close it.

A background watcher checks every few seconds for a known game process. The instant one launches, other background apps drop to a lower CPU scheduling priority — never suspended, never closed — and the game itself gets priority. The moment it exits, everything returns to normal automatically.

  • Streaming software is never touched: OBS, Streamlabs, XSplit, NVIDIA Broadcast, Elgato tools
  • Voice chat stays smooth: Discord, Teams, TeamSpeak
  • Every activation and restoration is written to the change log
