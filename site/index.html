Modules

Every module, one purpose

Each one reads the real setting first, tells you what it will change and how risky that is, and logs the old value before touching it.

Game Mode & Game DVR

WindowsLow risk

High Performance so the CPU stops downclocking, and non-essential startup helpers off. Gaming platforms are never touched.

GPU scheduling

Hardware-accelerated GPU scheduling for lower latency on supported cards. Needs a restart, so it's opt-in.

NVIDIA max performance

Power management, threaded optimization, texture filtering and V-Sync, set through NVIDIA's own NVAPI.

NetworkLow risk

Network throttling

Removes the roughly 10,000 packets per second cap Windows applies while a multimedia or gaming task runs.

MemoryLow risk

RAM cleaner
